# Example apps

Standalone Expo apps built with plocks (`@plocks/ui`). Each app has its own run instructions and an interactive screen.

- [The Daily Edition](https://github.com/platform-blocks/examples/blob/main/apps/daily-edition/README.md) — An editorial news reader with sections, article detail, and a saved list. Stories are original sample content; no live feed.
- [Lettergrid](https://github.com/platform-blocks/examples/blob/main/apps/lettergrid/README.md) — A five-letter word game with six guesses and position-aware color clues.
- [Calculator](https://github.com/platform-blocks/examples/blob/main/apps/calculator/README.md) — A four-function calculator with decimals, percent, sign change, and chained operations.
- [Idea Grid](https://github.com/platform-blocks/examples/blob/main/apps/idea-grid/README.md) — A searchable idea grid with detail views and saved pins. Art and ideas are local placeholders.
- [E-Reader](https://github.com/platform-blocks/examples/blob/main/apps/e-reader/README.md) — A modern story reader with spoken narration, word highlighting, and saved reading progress.
- [Wordtrail](https://github.com/platform-blocks/examples/blob/main/apps/wordtrail/README.md) — A four-question beginner Spanish lesson with answer feedback, progress, and score.
