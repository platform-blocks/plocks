# 0.3.0

This release rebuilds `Knob` around a physical body renderer and grows its visual variants from five to seventeen.

## Components

- Add `Toolbar`: a row or column of toggles with `Toolbar.ToggleGroup` (`type="single"` or `"multiple"`), `Toolbar.ToggleItem`, standalone `Toolbar.Toggle` and `Toolbar.Divider`. Every toggle shares one tab stop; arrow keys move across groups and dividers, Home/End jump to the ends.
- Add `WaffleChart` to `@plocks/charts`: a part-to-whole grid of cells allocated in proportion to each segment's value, with `total`, `rows`/`columns`, `fillDirection`, `emptyColor`, legend and tooltip.
- Add `MatrixChart` to `@plocks/charts`: an x/y heatmap over string-keyed cells with `null` for empty slots, column label rotation and position, a color ramp with `domain`, `getCellProps`, tooltip and a Less/More legend.
- Add a `success` state to every form field: a string or node renders in the success color where helper text goes and describes the control; text fields, pickers, `Select`, `AutoComplete`, `ColorInput`, `TextArea` and `PinInput` also draw a success border. `error` wins over `success`.
- Add `variant="light"` to `Checkbox` and `Radio`: a checked control takes the shared light tint and draws its check or dot in the accent color.
- Add `interactive` to `Tooltip`, which keeps the tooltip open while the pointer moves onto it so links and text inside are reachable.
- Add `returnFocus` to `HoverCard`, and keep a hover card open while keyboard focus moves from its target into the card.
- Add `disableCollapse` to `Accordion`, so pressing the open item no longer closes it.
- Add `labelPosition` to `Stepper`: `'right'` puts each label beside its icon in horizontal steppers. `'bottom'` is the default and today's layout.
- Add `opposite` and `alternate` to `Timeline.Item`. Any item with `opposite` switches the timeline to the centered layout.
- Add `visibilityToggleFocusable` to `PasswordInput`.
- Add `dropdownFullWidth` to `ColorInput`, so the swatch dropdown matches the field's width.
- Add `renderPill` to `TreeSelect` for custom selected-value pills in `multiple` and `checkbox` modes.
- Add `withAutoCloseProgress` to `Toast` and `ToastProvider`: a line along the bottom edge shrinks over the auto-hide time and pauses with it.
- Add `layout="stacked"` to `ToastProvider`: the newest toast shows in full with older ones peeking behind it, expanding on hover, focus or press.
- Add `onLongPress`, `onPressIn`, `onPressOut` and `delayLongPress` to `Card`. Any press handler makes the card pressable, not only `onPress`, and `disabled` blocks all of them.
- Add `pressedStyle` to `Card` and `Block`. On `Card` it replaces the variant's press feedback, e.g. `pressedStyle={{ opacity: 0.7 }}`; on `Block` it is the only press feedback.
- Add `delayLongPress` to `Block`.
- Add `translateX`, `borderBottomLeftRadius` and `borderBottomRightRadius` to `Block`.
- Add `useLongPress`, which fires after a press is held for `threshold` ms (default 400) on native and web, and cancels on release, leave or `onTouchCancel`.
- Add `scrollHost` to `useScrollSpy`, an element or ref used as the observer root and scroll target, for headings inside a nested scroll container.
- Add `referenceLines`, `referenceAreas` and `referenceDots` to `LineChart`, `AreaChart`, `BarChart`, `ComboChart` and `ScatterChart`. `BarChart` accepts a category label or index for x.
- Add `hideDetached` to `Tooltip`, on by default. On web, an open tooltip hides while its trigger is removed, hidden, zero-sized, or scrolled out of view, and comes back when the trigger is visible again.
- Add `presets` to `TimePicker` and `TimePickerInput`, as 24-hour strings or `{ label, values }` groups shown as quick-pick buttons. Add `closeDropdownOnPresetSelect` to `TimePickerInput`.
- Add `withNativeLevelSelect` and `yearsSelectRange` to `Calendar`, `DatePicker`, `DatePickerInput`, `MonthPicker` and `MonthPickerInput`. On web, the header's level button becomes month and year selects; native keeps the button.
- Add a right y-axis to `ScatterChart`: pass `yAxisRight`, bind a series with `yAxis: 'right'`, and fix its range with `yDomainRight`.
- Add `layout="stream"` to `AreaChart` and `stackMode="stream"` to `StackedAreaChart`: a streamgraph centered on a moving baseline, with the y axis hidden by default.
- Draw `referenceLines`, `referenceAreas` and `referenceDots` on `StackedAreaChart` and every `AreaChart` layout. In percentage mode, y values are fractions from 0 to 1, matching the axis.
- Add `BulletChart` to `@plocks/charts`: a value against a target marker and qualitative range bands, horizontal or vertical, with several bullets on one shared scale through `data`.
- Add `SunburstChart` to `@plocks/charts`: hierarchical data as concentric rings, with branch colors tinted per level, labels only where they fit, path highlighting, and `zoomOnClick` drill-down.
- Add `CalendarHeatmapChart` to `@plocks/charts`: daily values keyed by `YYYY-MM-DD` laid out as a calendar, with month labels on top or bottom, weekday labels, `splitMonths`, `firstDayOfWeek`, a legend and a tooltip.
- Add `withBrush` to `LineChart`, `AreaChart`, `StackedAreaChart`, `BarChart` and `ComboChart`: a range selector with a miniature preview under the x axis, keyboard-operable handles, `brushProps`, and controlled `brushRange` with `onBrushChange`. Add the public `ChartBrush` component.
- Add zoom to `Lightbox`: double-tap, pinch, ctrl or ⌘ + wheel, the `+` `-` `0` `Z` keys and a zoom button, with clamped panning while zoomed. Add `allowZoom` and `maxZoom`.
- Add video slides to `Lightbox` (`{ type: 'video', src, poster }`): a `<video>` element on web, `expo-video` on native when installed, and a poster with `onVideoPress` otherwise. Add `renderSlide`, expose `thumbnailSize`, and toggle thumbnails with `T`.
- Add `useAppShellResize` and the `AppShell` `resize` prop: drag, touch and keyboard resizing of the navbar, aside, header and footer, with drag-to-collapse and an optional `storageKey`.
- Add `activeColor`, `inactiveColor`, `indicator`, `borderColor` and `badgeColor` to `BottomAppBar`, so the bar can follow an app's own palette; `indicator={false}` hides the active pill and a color string tints it. An item's `icon` and `activeIcon` may be a function of `{ active, color }`. The active label is now semibold.
- Add twelve `Knob` variants. Interface: `outline`, `material`, `neumorphic`. Metering: `segmented`, `led-ring`, `gauge`. Hardware: `knurled`, `encoder`, `soft-touch`, `chickenhead`, `skirted`, `fluted`. Rebuild `retro` as a domed hardware knob.
- Add `appearance.body` and `Knob.Body` for the knob's body: `circle`, `polygon`, `fluted`, and `chickenhead` shapes; `dome`, `concave`, `matte`, `metal`, and `brushed` shading over any color; custom gradients; rim grip textures; a cap and a skirt; and stacked soft shadows. Bodies with a shape or grip turn with the value while their lighting stays fixed.
- Add `Knob` pointer shapes: `line`, `needle`, `notch`, `dot`, `dimple`, and `triangle`, plus `inset` to start a line away from the center.
- Add `glow` and `cap` to `Knob` tick layers, for LED rings and hard-edged segments.
- Let `ring: false` (or `ring.visible: false`) hide the `Knob` track while ticks, thumb, and pointer keep its geometry.
- Merge a `Knob` variant's appearance with yours at every depth, so `appearance={{ body: { cap: { color } } }}` keeps the rest of the preset's cap.
- Keep the `digital` and `studio` arms clear of the centered value.
- Mount a `ToastProvider` in `PlocksProvider`, so `useToast()` works with no setup. Configure it with `toast` (e.g. `toast={{ defaultPosition: 'bottom-center' }}`) or pass `toast={false}` to leave it out.
- Fill a `Button` that has a `color` and no `variant` in that color, with contrasting text. An explicit `variant` still wins.
- Add `flex` to `Button`, so buttons can share a row without a wrapping `Block`.
- Add `stroke` to `Text`: a color for a 1px outline, or `{ c, w }` for color and width. Pair it with `c="transparent"` for outline-only text. Web draws a true `-webkit-text-stroke`; native approximates it with a `textShadow` halo.
- Add `send`, `paperclip`, `thumb-up`, `thumb-down`, `flame`, `bell-ringing`, `player-skip-forward`, `player-skip-back`, `circle-check`, `dots-vertical`, `mood-plus` and `users` to the built-in `Icon` registry, with filled variants for the thumbs, flame, bell, skip and circle-check glyphs. Add `eye-off` and `map-pin` aliases for `eyeOff` and `location`.
- Add `value` and `defaultValue` to `FileInput`, and rename `onFilesChange` to `onChange`. A controlled list follows `value`, so a file removed outside the input frees its `maxFiles` slot. `onChange` also fires on upload status and progress.
- Add `focused` and `flex` to `TextArea`. With `flex`, the field fills its parent's height and the text box takes the space the label and footer leave.
- Accept `onFocus` and `onBlur` in `textInputProps` on `Input`, `TextArea` and the other text fields. They run alongside the field's focus ring instead of replacing it.
- Add `compact` to `Stepper`: horizontal steppers show only the step indicators, with the active step's label and description centered below. Takes a breakpoint map, e.g. `compact={{ base: true, md: false }}`.
- Add `p` to `Dialog`'s `openDialog` config and `useSimpleDialog` options.
- Add `withBorder` to `EmojiPicker` in `@plocks/emoji-picker`. `withBorder={false}` drops the picker's border, radius and background so it sits flush inside a `Popover`, `Dialog` or sheet.
- Add `domainPadding`, `xDomain` and `yDomain` to `CandlestickChart`. By default the data is inset half a candle slot on x and 8px on y, so candles and wicks clear the plot edges.

## Fixes

- Stop `ComboChart` from breaking the rules of hooks when the number of drawn points changes: each bar is its own component, and line series no longer return before their hooks.
- Keep `Highlight`'s surrounding font family, size, weight, line height and letter spacing on marked fragments, whether set through `style` or the `size`/`ff`/`fw`/`lh`/`lts` props. Marks were drawn at the 16px theme font.
- Fill an `Image` sized by a width and `aspectRatio`. On web, a bundled asset kept its intrinsic height and was cropped by the box.
- Stop `variant="unstyled"` fields from drawing the focus ring. `Input`, `TextArea` and the other field frames show no frame and no ring when unstyled.
- Size `TextArea` by `h` on web. The shared `flex: 1` input style became `flex-basis: 0%` and collapsed the box to its `rows`.
- Size a `Popover` dropdown without `w` to its content, within the viewport and `maw`. It was locked at 200px and clipped wider content such as an emoji picker.
- Let `Dialog`'s `p`, `px`, `py`, `pt`, `pb`, `pl` and `pr` set the body padding in every variant. `p={0}` now runs content edge to edge; before, the default 20px padding won on native.
- Send the global `toasts` API to the innermost `ToastProvider`, so a nested provider gets every toast and none shows twice.
- Space the `EmojiPicker` title from the skin-tone row, and let the row scroll instead of running into the title.
- Draw `HeatmapChart` cell labels and legend text in the chart theme's `fontFamily`. On web, SVG chart text with the default `'System'` family now renders sans-serif instead of serif.
- Stop `ComboChart` from cutting right-axis labels short, such as "30%" shown as "30...".
- Keep the web version of platform-split modules intact in the published build of `@plocks/ui` and `@plocks/dates`. Rollup tree-shook their callers against the native implementation, so `FileInput` on web made no image previews: `createImagePreview` lost its arguments and `preventWindowFileDrop` was dropped.
- Keep `Video`'s elapsed-time readout in step with the seek bar. For YouTube sources, play, pause and seek update the readout immediately.

## Documentation

- Add `Knob` hardware-variant and custom-body examples, and body, finish, and pointer controls to the `Knob` playground.
- Document selectable cards: `role="option"` with `aria-selected`, or `role="radio"` with `aria-checked`.

## Upgrading

`LightboxItem` is now a union of image and video items. Code that reads `item.uri` must first narrow with `item.type !== 'video'`, or type its data as `LightboxImageItem[]`.

`Tooltip` now hides while its trigger is detached or scrolled out of view. Pass `hideDetached={false}` to keep it visible.

`ScatterChart` points without their own color now use their series color, matching the legend and tooltip. Before, each point took a palette color by index.

`Tooltip` no longer stays open when the pointer moves onto it. Pass `interactive` to keep the old behavior.

`PasswordInput`'s show/hide toggle, and the one on `Input type="password"`, is no longer a Tab stop. Pass `visibilityToggleFocusable` to put it back in the tab order.

A `Block` with `onPress`, `onLongPress`, `onPressIn` or `onPressOut` is now a button (`role="button"`) unless you pass `role`. Pass the role it should have, or `role="none"` to keep it unannounced.

`Knob`'s `appearance.fill` is now `appearance.body`, and `Knob.Fill` is now `Knob.Body`. The old fill options (`color`, `borderWidth`, `borderColor`, `radiusOffset`) carry over unchanged.

`PlocksProvider` now mounts a `ToastProvider`. An app's own `ToastProvider` keeps working: inside `PlocksProvider` it takes over, and above it the built-in one is skipped. `CopyButton` now confirms copies with a toast on web by default. Pass `toast={false}` to keep the old behavior.

`FileInput`'s `onFilesChange` is now `onChange`, and it also fires on upload status and progress updates.

A `Button` with a `color` and no `variant` now renders `filled`. Pass `variant="default"` to keep neutral chrome.

Every `Knob` variant except `default` and `encoder` now sets its own sweep: 270° for most, 240° for `gauge` and `chickenhead`, and 300° for `skirted`. A knob that passes a variant and relied on the full circle should set `appearance.arc` explicitly. Hardware variants and `gauge` place the value label below the knob unless `valueLabel.position` is set.
