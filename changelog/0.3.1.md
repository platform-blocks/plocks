# 0.3.1

This release adds `Waveform` regions and an external playhead, key-up hotkeys and held-modifier tracking, and fixes how dialogs and field labels read to assistive technology on web.

## Components

- Add `regions` and `onRegionPress` to `Waveform`. Each region (`start`, `end`, `label`, `color`, `active`, `disabled`) is a named button inside a group, and works on an empty waveform too. The active region is marked `aria-current`.
- Add `playhead` to `Waveform`: a number or a Reanimated shared value. Only the playhead line moves; the waveform does not re-render.
- Let a `useHotkeys` or `useGlobalHotkeys` binding be `{ keydown, keyup, repeat, preventDefault }`. Key-up follows the physical key of the matched press, and blur, ⌘ release and unmount end held presses. Modifiers can bind on their own (`'shift'`, `'alt'`, `'mod'`), and `'space'` names the space bar. Function handlers behave as before.
- Add `useModifierKeys` and `getModifierKeys`: one capture-phase tracker of held modifiers, fed by key and pointer events and cleared on blur.
- Add `serverViewport` to `useViewport`, `BreakpointProvider` and `PlocksProvider`: the size used for prerender and hydration instead of the desktop default, with no hydration mismatch.
- Add `destructive` and `variant` to `useSimpleDialog`'s `confirm`. `destructive` draws the confirm button in the error colour; `variant="bottomsheet"` opens the prompt as a sheet.
- Export `validationRules` and `validateValue` from the package root, along with the `ViewportSize`, `UseViewportOptions`, `HotkeyHandler`, `HotkeyHandlers`, `ModifierKeysState` and `WaveformRegion` types.

## Fixes

- Stop `Dialog`, `DropdownSheet` and `Lightbox` from reading as two nested dialogs on web. react-native-web's `Modal` added an unnamed `role="dialog"` window around the content; the dialog role and name now sit on one full-window wrapper, so popovers, menus and tooltips opened inside stay inside the dialog.
- Render the label of `Input`, `NumberInput`, `TextArea` and `AutoComplete` as a real `<label for>` on web, keeping `aria-labelledby`.
- Render `Dialog` titles as `<h2>` at the same h3 size, so a dialog opened over a page's `<h1>` keeps heading order.
- Type the `edges` prop that `SafeArea` already forwarded.
- Fit a `Chip` label's line height to its font size. A small chip's label sat in a box too tall for it.

## Documentation

- Document `variant="none"` on `Button` and `IconButton`: the unstyled pressable that keeps the button role, focus ring, press feedback, haptics, `disabled`, `tooltip` and `onLongPress`.
- Show a Since line, the release that added it, on every component and hook page. Pages that were marked beta or experimental are now stable.
