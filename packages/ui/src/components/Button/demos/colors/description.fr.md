Associez `color` à une variante colorée (`filled`, `light`, `subtle`, `outline`, `gradient`) pour relier chaque action à une couleur sémantique. Sans `variant`, `color` seul donne un bouton `filled` dont le texte contraste automatiquement. Un `variant="default"` explicite reste neutre et ignore `color`.
